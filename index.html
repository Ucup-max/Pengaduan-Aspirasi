Panduan Menghubungkan Supabase Cloud

1. Buka Supabase Dashboard Anda di supabase.com.

2. Jalankan seluruh perintah SQL di berkas supabase_schema.sql melalui menu SQL Editor Supabase.

3. Salin Project URL dan Anon Public Key dari menu Project Settings > API.

4. Buka berkas index.html ini, lalu ganti nilai variabel pada baris script:

const SUPABASE_URL = 'https://hbekdutsineitvrghcui.supabase.co';
const SUPABASE_ANON_KEY = 'sb_publishable_npHOglpUjq9kS9--oy6Teg_Iqbb9-bn';

*Jangan pernah memasukkan service_role secret key di kode frontend browser.
